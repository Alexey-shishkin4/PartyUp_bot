# Источники Fortnite и лимиты

Проверено 24 ноября 2026 года. Лимиты ниже относятся к запросам API. Один импорт может обращаться к нескольким источникам.

| API | Запросы в минуту и час | Запросы в день | Какие данные берём |
| --- | --- | --- | --- |
| [Osirion Public API](https://fnapi.osirion.gg/) | 50/мин для запросов об аккаунтах, подтверждено заголовками при проверке поиска, наигрыша и рангов. Отдельный часовой лимит не опубликован. Лимит 100/мин относится к другим категориям. | Отдельный лимит не опубликован. | Публичный поиск по нику Epic, наигрыш за всё время по устройствам и размерам команд, текущие ранги по рейтинговым трекам. Эндпоинт статистики принимает сезон или всё время. |
| [api-fortnite.com](https://www.api-fortnite.com/#pricing) | Для статистики отдельные значения в минуту и час в проверенных публичных материалах не указаны. | 10 000 Free, 500 000 Pro по текущей странице тарифов. Лимит сбрасывается в полночь UTC. | [Статистика по ID](https://prod.api-fortnite.com/swagger/index.html) принимает `startTime` и `endTime` в Unix-секундах. Это источник статистики за 30 дней и наигрыша по плейлистам за всё время. Эндпоинт поиска по имени служит запасным при недоступности Osirion. |
| [fortnite-api.com](https://dash.fortnite-api.com/endpoints/stats) | Публичные численные лимиты для BR Stats не нашлись. В боте установлен локальный потолок 30/мин. | Публичный численный лимит не нашёлся. | Резервный BR-наигрыш и поиск по нику. Доступны сезон или всё время и разбиение по размеру команды. |
| [Fortnite Data API от Epic](https://dev.epicgames.com/documentation/fortnite/using-fortnite-data-api-in-fortnite) | Для выбора источника личной статистики неприменимо. | Для выбора источника личной статистики неприменимо. | Агрегаты по островам. Отдельные профили игроков в этом API недоступны. |

Цифры в [старом разделе SDK](https://documentation.api-fortnite.com/) расходятся с текущим тарифом api-fortnite.com. По умолчанию бот ограничивает этот источник 10 000 запросами за сутки в одном процессе. Если у ключа другой лимит, укажи его в `API_FORTNITE_DAILY_LIMIT`. Бот также учитывает HTTP 429 и заголовки сброса квоты. Для расчёта пропускной способности 50/мин соответствует максимуму 3 000 запросов в час при непрерывной работе. Это арифметическая оценка, а не отдельная квота поставщика.

## Как считается статистика

1. Бот сопоставляет отображаемое имя с Epic Account ID. Обновление идёт по ID. Импорт использует публичную статистику.
2. За последние 30 дней бот агрегирует отдельные плейлисты в режимы. Любимый режим определяется по наигранным минутам, при равенстве — по числу матчей. Если минут нет, используются доступные счётчики матчей. Общие показатели и пересекающиеся разбивки по устройствам повторно не суммируются.
3. Ранг определяется по текущему рейтинговому треку этого режима. Часы по размеру команды и часы по режиму сохраняются раздельно. Например, часы в дуо могут включать несколько режимов.
4. В PostgreSQL аккаунт хранится в `fortnite_accounts`, а минуты, матчи за период и ранги по режимам — в `fortnite_mode_stats`. Неполное обновление сохраняет последнюю доступную статистику и дату, на которую она была рассчитана.

Общий наигрыш относится к данным, которые видит выбранный API. Эти данные могут не охватывать все острова Creative и отдельные режимы Fortnite. Без `API_FORTNITE_KEY` бот может получить ник, наигрыш и ранги через Osirion, но любимый режим за 30 дней будет недоступен. Сезонная статистика не подменяет запрос за 30 дней.
